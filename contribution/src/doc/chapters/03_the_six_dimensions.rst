The six dimensions
==================

Each dimension is scored 0 to 5 by stated rules, and the aggregate applies a weighted blend of mean and
minimum, so that one weak dimension cannot be hidden by five strong ones.

.. list-table::
    :header-rows: 1

    * - Dimension
      - What it asks
      - Mean (n=12)
      - Range observed
    * - Purpose
      - does the artifact state an action and an object
      - 5.0
      - 5.0 – 5.0
    * - Usage
      - does it show how the artifact is invoked
      - 2.0
      - 2.0 – 2.0
    * - Behavioural
      - does it state what the artifact does when run
      - 5.0
      - 5.0 – 5.0
    * - Fields
      - are the required fields present and populated
      - 1.5
      - 1.0 – 3.0
    * - Conciseness
      - is the text free of repetition and padding
      - 4.0
      - 1.0 – 5.0
    * - Context
      - does it state when the artifact applies and when it does not
      - 1.9
      - 1.0 – 2.0
